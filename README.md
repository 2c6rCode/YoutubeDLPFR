## 📖 About

**yt-dlp GUI** is a modern Windows desktop frontend for [yt-dlp] (https://github.com/yt-dlp/yt-dlp).

It is designed for users who want the power and flexibility of yt-dlp without having to constantly search for command-line arguments or remember complicated commands.

Instead of opening a terminal and figuring out which options you need, the application provides a clean graphical interface for managing downloads.

THIS IS THE BETA VERSION I WILL TRY TO IMPROVE THE GUI MORE

> **Note:** This project is a graphical frontend for yt-dlp. yt-dlp itself performs the actual media extraction and downloading.
